# Технологическая практика (Вариант 2)
| Столбец | Описание | Тип данных |
| :--- | :--- | :--- |
| **Country** | Страна | Категориальное значение |
| **Region** | Регион | Категориальное значение |
| **Year** | Год | Категориальное значение |
| **Water Source Type** | Тип источника воды | Категориальное значение |
| **Water Treatment Method** | Метод очистки воды | Категориальное значение |
| **Healthcare Access Index (0-100)** | Индекс доступа к здравоохранению | Счётное значение |
| **Urbanization Rate (%)** | Уровень урбанизации | Счётное значение |
| **Sanitation Coverage (% of Population)** | Охват санитарными услугами | Счётное значение |
| **Temperature (°C)** | Температура | Счётное значение |
| **Population Density (people per km²)** | Плотность населения | Счётное значение |
| **Cholera Cases per 100,000 people** | Число случаев заражения холерой | Счётное значение |
| **Typhoid Cases per 100,000 people** | Число случаев заражения брюшным тифом | Счётное значение |
| **Infant Mortality Rate (per 1,000 live births)** | Число случаев младенческой смертности | Счётное значение |
| **GDP per Capita (USD)** | ВВП на душу населения | Счётное значение |
| **Rainfall (mm per year)** | Количество осадков | Счётное значение |

## Требования
* **Python:** 3.6 или выше
* **Зависимости:** `pip install -r requirements.txt`
